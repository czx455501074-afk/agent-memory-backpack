# 记忆质量改进（2026-10-20）

针对归属、类型、短期状态固化、噪声收录与检索遗漏，参考 [五个同类系统的一手研究](peer-memory-systems-2026-10-20.md)，在现有 SQLite/HTTP/MCP 架构内改进。研究区分当前源码、旧接口和产品宣传，没有把对手性能数字当作本项目实测。

## 数据结构与执行边界

| 维度 | 保存位置 | 行为 |
|---|---|---|
| 内容类型与全局/项目/任务归属 | 现有 kind、scope | 根据来源配置和审核决定；task 沿用会话绑定，不是新建 session 权限隔离体系 |
| 复用价值、持久性、混合上下文与复验要求 | classification.assessment | 区分 reusable/episodic/noise/uncertain 与 durable/temporary/unknown |
| 提交者声明、适用/失效条件 | memoryContext → applicability | 是可复查的文字条件，不是自动环境检测，不提升权限或证据等级 |
| 失效时间与理由 | validity | 到期退出检索、注入、门禁；保留记录和修订；读取不续期 |

确认语和无信息文本获得幂等拒收回执，不进入模型审核。不会仅因文本短就删除事实。相同正文但任务/适用条件不同，不再错误合并。

自动捕获故障归为未验证 journal。暂态事实有 taskId 时留在来源任务，采纳后最多七天有效；不能直接升格为全局知识、硬规范、技能或工作流。该约束在服务端实际写入时重算，旧快照和确认标志不能绕过。可复用方法应作为新结论提交，给出适用条件与验证依据；“429 的重试方法”和“今天接口 429”有不同生命周期。模型建议可以收紧审核，不能自行批准、删除或扩大范围。

普通“全局变量/通用函数”和否定全局适用的句子不再扩大范围。经验引用 URL 不再仅凭链接变成材料。混合类型建议保留真实原文，去掉“规范要求部分”等占位符；相似度不再提高类型/范围置信度。多日期事件、多 Task 段落会标记为混合历史，读取时带审慎提示。

## 扫描导入与存量数据

旧 candidateToKnowledge 无条件 global。现在 CLI discover/adopt/rescan 与核心定时扫描传递来源上下文，项目来源采用项目范围，同文不同项目使用不同 id。用户技能/规范目录可以保持全局；共享 memories 目录只代表存放位置，不能证明内容全局适用，归属不明时停止自动采纳并保留来源。可用 adopt --project PROJECT 明确目标后先检查干跑再采纳。来源刷新保留已有作用域，不覆盖此前的范围决定。

只读审计：

```powershell
npm run build
node scripts/memory-quality-audit.mjs --samples 30
```

脚本使用 SQLite readOnly，只发 SELECT，不创建 Store，不改内容或表结构，默认不输出正文或凭据。2026-10-20 00:29（上海）快照：231 条 active（46 memory / 34 journal / 4 norm / 147 skill）；发现 8 份混合历史 memory、7 份 global journal 待核对。10 条 pending 中 1 条范围建议与旧判定不同。这些是审查线索，不是全量人工标注的错误率。

初次粗筛曾把三份历史合集标为暂态事实；读源后发现其中混有仍有效的方法和旧状态，故改为复合历史，不给整篇套一个 TTL。既有 reclassify 只重算待审分类快照，记录版本、摘要和前一判定，不改已生效规范。存量合集仍需按来源逐事件整理，不能仅靠关键词批量删改或猜测项目。

## 检索完整性

显式搜索合并模型选择与全文命中，避免模型选少数条后截掉本地证据；自动注入保留原保守门槛。支持 kind、scope、taskId、offset；page 提供 total/hasMore/nextOffset/searchSnapshot。续查带 knowledgeRevision 和 searchSnapshot，识别修订、排序或有效期变化并要求重新查询。

搜索节选定位命中正文，保留原文 offset。query 正文读取支持 passageOffset，回执报告匹配窗口总量、下一页、未读范围和关联条目。日记正文包括 problems、unfinished；读取返回 scope、provenance、evidence、有效期和质量判定。两个宿主工具及技能说明同步了续查方法。

coverage.complete 仅描述本条正文是否完整返回。匹配窗口读完不等于主题查全；missingTerms 是字面线索，不证明库内没有答案。协议能暴露未读状态，不能保证任意模型都会遵守。没有构建强制“必须全库通读”门禁。

## 验证与局限

新增行为测试覆盖噪声拒收/重试、任务去重、旧候选采纳约束、到期不续期、门禁和检索一致、跨项目/任务隔离、模型漏选后的分页、段落续读、来源归属、共享历史待审及浏览器日记表单。

原有测试按新语义调整：自动失败期望 journal；幂等采纳夹具去掉“一次性”任务限定；日记读取断言包含完整 problems。没有放宽这些测试原本验证的幂等性、信任或完整性约束。全量输出在 .local/memory-quality-full.log，部署核验记录另附验收文档。

尚未证明长期 agent 行为收益，未完成旧合集逐事件拆分、全量项目归属迁移或原生 session scope。后续需要独立人工标注集测作用域错扩率、过时建议误注入率、多资料证据覆盖率和额外 token/延迟；不能用字段数量和测试数替代“越用越聪明”的证据。
