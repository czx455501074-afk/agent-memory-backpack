## 执行与恢复

回滚是向前修订：原件恢复旧内容为新修订，新增归纳条目退役，所有历史保留。迁移后若有人修改了条目，回滚拒绝覆盖其后续工作。

```powershell

node scripts/curate-memory.mjs --prepared .local/memory-curation-20261020/prepared.json --yes
node scripts/curate-memory.mjs --rollback memory-curation-20261020-v1 --yes
```
