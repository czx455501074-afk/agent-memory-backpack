## 二、F22：为什么你的 Codex 被卡死（最严重）

### 现象
Codex 会话报告："目前测试被环境拦截，尚未执行任何操作。Agent Memory Backpack 的策略服务不可用，自动审批钩子因此拒绝了报告读取、账户额度查询和电脑控制调用。"

### 根因
**核心进程没在运行**（`core.lock` 里是陈旧 pid，47631 端口无监听），而 **PreToolUse 钩子是 fail-closed**：
够不到策略服务就**拦截每一个工具调用**。一个可选的知识服务，把整个 agent 锁死了。

### 因果证据（对照实验）
同一份输入，只改"核心答不答"：

| 钩子副本 | 核心不可达时 |
|---|---|
| marketplace（Codex 当时跑的） | **`deny`** |
| 仓库源码 | **`allow`**（降级放行） |

**修复早已在源码里**（注释写明"服务不可达 ≠ 本次调用被拒"），是 Codex 跑的那份**副本过期**了
（缺 `gate-cache.mjs`/`ensure-core.mjs`/`spool.mjs`）。已重新部署并验证 **正反例 5/5**：
快照里记录的禁令仍拦、未禁令放行、空快照不凭空拦截。

## 三、F24：Codex 侧整份 runtime 都是旧的（比 F22 更根本）

用插件操控真实 Codex 时发现：`amb_prepare` 正常，但 `amb_search_universal` **不存在**。

核对三处副本：

| | marketplace `runtime/` | Codex 缓存 `runtime/` | 仓库 `dist/src` |

| 缺失 | 6 个文件（capabilities/material/policy/semantic/service/ui） | 同左 | — |

**Codex 跑的是一份很旧的核心，之前整轮 R0–R4 的修复都没部署到这一侧。**
这也补全了 F22 的解释：不只是"核心没跑"，它那份**钩子本身也是旧的 fail-closed 版本**——同源。

**修复**：重建 → 同步 marketplace runtime → 同步 Codex 缓存 → 重启核心（停前核对命令行确认归属）→
重启 Codex 的 MCP 服务。三处 runtime 现 **20/20 逐文件一致**。

## 四、F23：插件自身 3 个输入层缺陷（源码级修复）

用**记事本**做判定基座（UIA `value` + 字符计数），因为 Codex 画布 OCR 会把"插件"读成"播件"，
**我一开始就因此误判过一次**（详见 §7）。

| 编号 | 缺陷 | 修复 | 验证 |
|---|---|---|---|
| **D1** | `activate:true` 夺走焦点 → **按键丢失，工具仍报 `ok:true`** | 激活后把焦点交还文本控件 | ✅ `value` 由不变 → `XY1239`，焦点保持 |
| **D2** | 文档写法 `Ctrl+A` **100% 报错**（`{CTRL+A}` 被 SendKeys 拒） | 接受合并写法、去掉大写化 | ✅ 全选生效，`Delete` 清空 |
| **D3** | 多主键**只发最后一个**，且响应回显全部（**上报误导**） | 逐个发送并如实上报 `chords` | ✅ `["1","2","3"]` → `XY123` |

**共同点：报成功、实际没输入**——比直接报错更危险。
修复后复核：Win 键黑名单仍拒绝、歧义写法明确拒绝、插件自检仍退出 0、
PowerShell 语法零错误、CRLF 一致。补丁副本已另存到 `node_modules` 之外。

## 六、一个由我造成的测试设计错误（如实记录）

我让 Codex"读上一步返回的第一个 id"，而上一步 `amb_search_workflows` 命中 0 条——
**我的测试指令自相矛盾**。Codex 报失败后我没有直接采信，而是查库确认：
**库里根本没有 workflow 类知识**（memory 16、norm 3、skill 146），所以返回 0 是**正确行为**。

那次失败的原样错误是：
```
Invalid arguments for tool amb_read_knowledge ... must match pattern /^[\p{L}\p{N}_.:-]+(@\d{1,9})?$/u at knowledgeId
```
**这恰好证明 H2 的校验收紧生效**——空 id 被正确拒绝并给出字段名。用真实 id 重测即成功。

## 七、我在这轮里犯的错误（不掩饰）

   但**已删掉缓存内容**，把 Codex 插件弄坏了。已从 marketplace 完整还原并逐项校验；
